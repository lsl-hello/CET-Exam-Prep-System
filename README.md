四六级刷题备考系统 完整改版设计（刷题 + 背单词双核心）
一、项目基础信息
1. 项目名称：六级刷题备考管理系统
2. 技术栈不变（前后端分离）
- 后端：SpringBoot + MyBatis-Plus + MySQL8 + Redis + SpringSecurity+JWT
- 前端：Vue3 + Vite + Element Plus + JavaScript
3. 角色三级权限（沿用原有逻辑，适配六级场景）
游客：仅首页介绍、六级考试简介，不能背单词、不能刷题、无任何学习功能
六级考生（普通用户）：完整刷题、背单词、错题本、单词本、学习报告、每日学习计划提醒
管理员：管理六级题库、六级单词库、用户管理、批量导入真题 / 单词、全局数据统计、公告管理

二、系统两大核心业务模块
模块 A：六级真题刷题模块（听力 / 阅读 / 翻译 / 写作，四六级标准题型）
模块 B：六级单词背诵模块（词书、记忆打卡、生词本、遗忘复习）
配套：错题分析、生词薄弱分析、每日学习计划、个人数据报表、翻译功能
